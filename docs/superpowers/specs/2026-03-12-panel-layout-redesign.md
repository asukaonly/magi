# 面板布局重设计

## 背景

当前人格设置和记忆页面以 Sheet 形式覆盖整个主界面，用户体验不佳。需要改为主界面右侧区域直接显示这些内容。

## 目标

- 聊天、人格、记忆页面在右侧区域直接显示，不再覆盖
- 设置页面保持弹窗形式
- 添加折叠功能，可折叠整个左侧区域

## 设计方案

### 布局结构

**当前布局**：
```
┌─────────┬────────────────────────────────────┐
│ 侧边栏   │         聊天界面                   │
│ +       │                                    │
│ 聊天列表 │  (人格/记忆以 Sheet 覆盖整个页面)   │
└─────────┴────────────────────────────────────┘
```

**目标布局**：
```
┌─────────────────────────────────────────────────────────────┐
│ [窗口控制]  │ [≡折叠]  │           标题栏                   │
├────────────┴────────────────────────────────────────────────┤
│         │                                                   │
│ 侧边栏   │                                                   │
│ +       │              右侧内容区域                          │
│ 聊天列表 │         (聊天 / 人格 / 记忆)                      │
│         │                                                   │
└─────────┴───────────────────────────────────────────────────┘
```

### 折叠后布局

```
┌─────────────────────────────────────────────────────────────┐
│ [窗口控制]  │ [≡]  │              标题栏                     │
├────────────┴────────────────────────────────────────────────┤
│                                                             │
│                    右侧内容区域（全宽）                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 页面处理

| 页面 | 改动 |
|------|------|
| **聊天** | 保持现有样式，只是不再被覆盖 |
| **人格** | 重新设计：顶部横排头像选择器 + 下方详情区域 |
| **记忆** | 保持现有样式，只是不再被覆盖 |
| **设置** | 不动，保持弹窗形式 |

### 人格页面设计

```
┌─────────────────────────────────────────────────────────────┐
│  [+]   [头像1]  [头像2]  [头像3]  [头像4]  ...              │
│  添加   人格1   人格2    人格3    人格4                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    选中人格的详情/配置                        │
│                                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

- 顶部：横向排列的人格头像选择器
- 第一个位置：添加自定义人格按钮（+ 图标）
- 点击头像：选中该人格，下方显示详情
- 下方：选中人格的配置详情（复用现有配置表单）

### 折叠功能

- **位置**：标题栏，侧边栏旁边
- **行为**：
  - 点击折叠 → 整个左侧（侧边栏+聊天列表）隐藏，右侧全宽
  - 再次点击 → 展开左侧，恢复原布局
- **按钮**：折叠后按钮保留在标题栏，可再次展开

## 技术方案

### 移除 Sheet 覆盖

当前实现：
- `Chat.tsx` 使用 `activePanel` 状态控制 Sheet 显示
- 路由变化时通过 `panelByPathname` 设置 `activePanel`

修改方案：
- 移除 Sheet 组件
- 直接在右侧区域渲染对应页面内容
- 设置页面保持 Sheet 形式

### 路由调整

当前所有页面都通过 `ChatPage` 组件渲染，需要调整：
- 聊天、人格、记忆：直接渲染在右侧区域
- 设置：保持 Sheet 弹窗

### 状态管理

- 使用现有的 Zustand store 管理折叠状态
- 新增 `isLeftPanelCollapsed` 状态
